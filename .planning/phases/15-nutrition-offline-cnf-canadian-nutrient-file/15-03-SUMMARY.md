## What Was Built

### EF Configurations (Task 1)

Three `IEntityTypeConfiguration<T>` classes auto-discovered by `ApplyConfigurationsFromAssembly`:

- **CnfFoodConfiguration**: PK on `FoodId` with `ValueGeneratedNever` (CNF FoodCode is externally assigned, not auto-incremented); `FoodDescription` max 300 required; `NormalizedDescription` max 300 indexed; `HasMany(ConversionFactors).OnDelete(Cascade)`.
- **CnfConversionFactorConfiguration**: Surrogate PK `Id`; `FoodId` indexed; `MeasureDescription` max 100 required. FK relationship configured from the principal side (CnfFoodConfiguration).
- **RecipeNutritionCacheConfiguration**: PK `RecipeId` with `ValueGeneratedNever`; `PerIngredientMatchJson` as TEXT column; `CanonicalDocHash` max 64 required (SHA-256 hex); 1:1 `HasOne(Recipe).WithOne().OnDelete(Cascade)`.

Three DbSets added to `CookBotDbContext`: `CnfFoods`, `CnfConversionFactors`, `RecipeNutritionCaches` (no existing DbSets disturbed).

### Migration (Task 2)

Generated `20260608030954_AddNutritionTables` via `dotnet ef migrations add`:
- `Up()` creates `CnfFoods` (PK FoodId not autoincrement), `RecipeNutritionCaches` (FK cascade to Recipes), `CnfConversionFactors` (autoincrement surrogate PK, FK cascade to CnfFoods); indexes on `NormalizedDescription` and `FoodId`.
- `Down()` drops in reverse FK order: CnfConversionFactors → RecipeNutritionCaches → CnfFoods.
- No existing tables touched; designer + snapshot generated by tooling.

### DatabaseSeeder Extension (Task 3)

Added `SeedCnfDataAsync(CookBotDbContext, string contentRootPath)`:
1. **Idempotent guard**: `if (await context.CnfFoods.AnyAsync()) return;` — mirrors the `context.Users.AnyAsync()` pattern.
2. **Pass 1** (foods): reads `seeds/nutrition/cnf_foods.json`, calls `IngredientNormalizer.Normalize` per food description to fill `NormalizedDescription`, inserts verbatim, `SaveChangesAsync`.
3. **Pass 2** (conversion factors): reads `seeds/nutrition/cnf_conversion_factors.json`, inserts verbatim, `SaveChangesAsync`. Runs only after Pass 1 commits (FK constraint safety).
4. Missing file → quiet return (T-15-06 mitigation — app still boots without nutrition).

Call site: immediately after `MigrateAsync()`, before the existing-user early-return, so it always runs on first startup.
