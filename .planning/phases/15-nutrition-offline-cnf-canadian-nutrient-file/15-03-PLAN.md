<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| seed files → database | The seeder reads committed JSON and inserts verbatim; values are not user-supplied and not modified. |
| recipe delete → cache delete | Cascade FK ensures a deleted recipe cannot leave an orphaned RecipeNutritionCache row. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-05 | Tampering | Verbatim CNF values modified during load | mitigate | Seeder inserts raw values with no arithmetic transform (OGL-Canada no-modification); the integration test round-trips fixture values unchanged. |
| T-15-06 | Denial of Service | Startup throws on missing/corrupt seed file | mitigate | Missing file → quiet return (nutrition unavailable, app still boots); deserialization guarded — startup never fails on nutrition seed issues. |
| T-15-07 | Tampering | Orphaned cache rows after recipe delete | mitigate | `OnDelete(DeleteBehavior.Cascade)` 1:1 FK in RecipeNutritionCacheConfiguration removes the cache when the recipe is deleted. |
| T-15-SC | Tampering | npm/pip/cargo installs | accept | No packages installed; EF Core + System.Text.Json already present. |
</threat_model>
