### 2. `src/CookBot.Infrastructure/Data/Configurations/AiUsageLogConfiguration.cs` (EF configuration)

**Analog:** `src/CookBot.Infrastructure/Data/Configurations/RecipeMadeConfiguration.cs`

**Why:** Direct precedent — same role (composite-index-bearing FK configuration for a timestamped log row with two FKs back to the same parent). Two parallel `HasIndex(... { UserId, CompletedAt })` declarations supply the exact M8-shape index Phase 9 needs.

**Excerpt to mirror — full file (`RecipeMadeConfiguration.cs`, lines 1–26):**

```csharp
using CookBot.Domain.Entities;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Metadata.Builders;

namespace CookBot.Infrastructure.Data.Configurations;

public class RecipeMadeConfiguration : IEntityTypeConfiguration<RecipeMade>
{
    public void Configure(EntityTypeBuilder<RecipeMade> builder)
    {
        builder.HasKey(r => r.Id);

        builder.Property(r => r.Notes).HasMaxLength(1000);

        // (UserId, CompletedAt DESC) supports the "Recently cooked" feed on Home.
        builder.HasIndex(r => new { r.UserId, r.CompletedAt });
        // (RecipeId, CompletedAt DESC) supports the per-recipe last-cook callout +
        // made-count surfacing in RecipeView.
        builder.HasIndex(r => new { r.RecipeId, r.CompletedAt });

        builder.HasOne(r => r.Recipe).WithMany().HasForeignKey(r => r.RecipeId)
            .OnDelete(DeleteBehavior.Cascade);
        builder.HasOne(r => r.User).WithMany().HasForeignKey(r => r.UserId)
            .OnDelete(DeleteBehavior.Cascade);
    }
}
```

**Translation rules for `AiUsageLogConfiguration`:**

- Composite index per PROD-14 + PITFALL M8: `builder.HasIndex(l => new { l.KeyOwnerId, l.Timestamp });` (the "DESC" hint is comment-only — SQLite ignores explicit direction on single-column index parts but the index serves the Phase 10 widget's `ORDER BY Timestamp DESC` aggregation).
- `Property(l => l.ModelName).HasMaxLength(80).IsRequired();`
- `Property(l => l.EstimatedCostUsd).HasColumnType("decimal(18, 6)");` (RESEARCH Item 1 — sub-cent precision required).
- Two `HasOne(...).WithMany().HasForeignKey(... )` lines for `User` (UserId) and `User` (KeyOwnerId). `OnDelete: Restrict` for KeyOwnerId (don't cascade-delete log rows when the key owner is deleted — telemetry has historical value); `OnDelete: Cascade` for UserId is acceptable.

**`CookBotDbContext` registration** (already auto-picked-up): `OnModelCreating` calls `ApplyConfigurationsFromAssembly` (line 30 of `CookBotDbContext.cs`) — no manual wiring required, only add `public DbSet<AiUsageLog> AiUsageLogs => Set<AiUsageLog>();` next to the existing `DbSet<RecipeTag>` declaration (line 26).

```csharp
protected override void Up(MigrationBuilder migrationBuilder)
{
    migrationBuilder.CreateTable(
        name: "RecipeTags",
        columns: table => new
        {
            Id = table.Column<int>(type: "INTEGER", nullable: false)
                .Annotation("Sqlite:Autoincrement", true),
            RecipeId = table.Column<int>(type: "INTEGER", nullable: false),
            Name = table.Column<string>(type: "TEXT", maxLength: 200, nullable: false)
        },
        constraints: table =>
        {
            table.PrimaryKey("PK_RecipeTags", x => x.Id);
            table.ForeignKey(
                name: "FK_RecipeTags_Recipes_RecipeId",
                column: x => x.RecipeId,
                principalTable: "Recipes",
                principalColumn: "Id",
                onDelete: ReferentialAction.Cascade);
        });

    migrationBuilder.CreateIndex(
        name: "IX_RecipeTags_RecipeId_Name",
        table: "RecipeTags",
        columns: new[] { "RecipeId", "Name" },
        unique: true);
}
```

**Generation pattern:** `dotnet ef migrations add AddAiUsageLog` after `AiUsageLog.cs` + `AiUsageLogConfiguration.cs` + `DbSet<AiUsageLog>` are in place. The generated CreateTable will include:
