<objective>
Build the Schema.org `Recipe` JSON-LD projector as a pure `CookBot.Application` function over the canonical v4 `RecipeDocument`, plus the hand-rolled ISO-8601 duration formatter it depends on. This plan delivers only the pure transform + its golden-file/unit tests — wiring into RecipeView's `<head>` is Plan 03.

Purpose: INTEROP-01/INTEROP-02 require a structurally valid Schema.org `Recipe` JSON-LD block, including `recipeCategory`/`recipeCuisine` derived from existing tags. The projection logic is a stateless transform with excellent golden-file affordances; building and locking it independently keeps it framework-free and fully testable before any Blazor integration.

Output: `JsonLdRecipeProjector.cs`, `Iso8601DurationFormatter.cs`, unit + Verify snapshot tests, and the committed `.verified.txt` baseline.
</objective>
