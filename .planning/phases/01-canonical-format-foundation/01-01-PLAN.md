<objective>
Establish the canonical Phase 1 foundation: pure additive code in `CookBot.Domain/Recipes/` (records) and `CookBot.Application/Recipes/` (singleton services), plus the `JsonSchema.Net` package add and DI wiring. After this plan ships, every other Phase 1 plan (parser rewrite, persistence, prompt consolidation, fixtures) consumes these contracts. No EF, no `PromptBuilderService`, no `IngredientRefDetectionService`, no `DatabaseSeeder` changes here.

**Purpose:** Build the canonical-record + serializer + validator + upcaster scaffold so downstream plans can run in parallel. This plan is the dependency root for the entire phase.
