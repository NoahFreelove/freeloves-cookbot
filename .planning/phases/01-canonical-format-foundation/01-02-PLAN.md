| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Injection | YAML→JsonNode adapter `ConvertGraph` fallback `JsonValue.Create(value.ToString())` | mitigate | Adapter never executes input as code; YamlDotNet returns inert primitive types only (no expression evaluation). The fallback `value.ToString()` materializes into a `JsonValue` — pure data. AC: code review confirms no `Process.Start`, `Eval`, or `Reflection.Invoke` paths in the adapter. |

AC: test suite includes one fixture with 10-level-deep nested structure (well within bounds; deeper input is application-level concern, not Phase 1 scope). |
| T-02-03 | Information Disclosure | `errors.Add($"Parse error: {ex.Message}")` in catch block | mitigate | `ex.Message` from STJ/YamlDotNet does NOT contain stack traces or internal state — only "Unexpected character at position N" or similar.
