# Plan 06-02: Cooking Mode rewrite

## Goal
Rewrite `Components/Pages/CookingMode.razor` markup against Phase 5 atoms per design handoff `screens/cooking.jsx`. Adaptive timer/step hero, always-on right rail, dark cocoa background. **All non-presentational behavior preserved verbatim** — JS-interop timers (`cooking-timers.js`), browser notifications, RecipeCookingAiContext, step navigation, recipe scaling.

## Tasks

### Task 1: Top bar + step rail (COOK-01, COOK-02)
- Replace existing top bar with minimal cocoa header: Exit button (left, navigates back) + recipe title (center) + step indicator ("step N of M") + notification chip (right, "notifications on" / "off") reading existing browser permission state via JS interop.
- Add a step rail directly below the header — N segments using `<div>`s; past steps use `rgba(255,255,255,0.5)`, current uses `var(--accent)`, future uses `rgba(255,255,255,0.12)`.

### Task 2: Adaptive hero (COOK-03)
Main split below the step rail: 1.6fr left + 1fr right. Left = hero region; right = ingredient rail (Task 3).

In left hero, conditional render based on `_currentTimerRunning` (existing field — verify name; add if missing):
- **Timer running** (`_currentTimerRunning && _remainingSeconds > 0`):
  - Eyebrow: existing step's timer label
  - 224px tabular numeral: `<div class="num" style="font-size:224px;line-height:0.92;font-weight:600;letter-spacing:-0.05em;color:var(--cream);">@FormatTimer(_remainingSeconds)</div>`
  - Controls row: 64px-circle Pause `CbButton accent` + "+ 30s" `CbButton subtle` + "Reset" `CbButton ghost`
  - 17px step text below (subdued cream)
- **Idle** (no timer running):
  - Eyebrow: "Step N"
  - 52px step text in cream
  - Buttons row: "Start N-min timer" `CbButton accent` (only if step has a timer) + "Ask about this step" `CbButton subtle` (hidden when AI off)

### Task 3: Always-on right rail (COOK-04)
- Eyebrow: "Ingredients · scaled {scale}×" (accent text "scaled 1.5×")
- Map `_recipe.Ingredients` (from canonical `RecipeDocument`); for each, render a row showing 22px tabular-numeral quantity + 14px name. Current step's referenced ingredients (from `step.IngredientLinks` — the `[name](#id)` link list) get an accent-tint background + border; non-referenced are dimmed (`color: rgba(255,255,255,0.5)`).
- Bottom widget: scale icon + "Serves {N}" + "scaled from {original}" + −/+ buttons. Clicking adjusts `_currentScale`; ingredient quantities re-scale live (existing `RecipeScalingService` integration).

### Task 4: Bottom step nav (COOK-05)
Below the hero region (left column): "Previous" (1fr, 64px height, ghost-style) + "Next" (2fr, accent, 64px). Each shows a 11.5px uppercase eyebrow ("Previous" / "Next") + 15px step name. Click handlers wire to existing `MoveToStep` API. Add `KeyDown` handler on the page for left/right arrow navigation if not already present.

### Task 5: Preserve JS interop + AI assist (COOK-06)
- `cooking-timers.js` JS interop: existing `startTimer(id, seconds, callback)`, `pauseTimer(id)`, `resetTimer(id)` calls preserved verbatim. The new buttons just trigger the same C# handlers.
- Browser notification on timer fire: existing `requestNotificationPermission()` flow + `Notification.show(message)` interop preserved.
- "Ask about this step" routes through `RecipeCookingAiContext` (existing service); button hidden when `UserProfile.AiEnabled = false`.

### Task 6: Build verify + commit
- `dotnet build` clean
- `dotnet test` baseline preserved
- Manual smoke: load a recipe in `/cook/{id}`, navigate steps, start a timer, verify it counts down, ingredients highlight, AI assist works (or is hidden when AI off).
