# Plan 06-03: Recipe View rewrite

## Goal
Rewrite `Components/Pages/RecipeView.razor` against Phase 5 atoms per design handoff `screens/recipe-view.jsx`. Editorial layout — 64px display title, 4-stat row, sticky 300px scaled-ingredient sidebar, hanging accent numerals on method, "Notes from your last cook" callout.

## Tasks

### Task 1: Editorial title block (RV-01)
2-column hero grid (1fr 1fr, gap 40px, items aligned to bottom):
- Left: eyebrow tags row (e.g. "Pasta · Italian · Weeknight" — pull from `RecipeDocument.Tags`); 64px display title using `.cb-recipe-cap` class; 17px lead paragraph from `RecipeDocument.Description`; 4-stat row (Active / Total / Serves / Made-count, each tabular-numeral 22px). Stats: `RecipeDocument.PrepTimeMinutes`, `(prep + cook)`, `RecipeDocument.Servings`, `await RecipeService.GetMadeCountAsync(recipeId)` (or compute from `RecipeMade.Count(rm => rm.RecipeId == id)` — pick whatever's easiest given existing services).
- Right: `<StripedPlaceholder Width="100%" Height="420" Label="hero photo · 4:3" />`.

### Task 2: Two-column body (RV-02)
Below the hero, grid `300px 1fr` with 56px gap:
- **Left sidebar** (sticky, top 80px):
  - Eyebrow "Ingredients"
  - Scale control card: `<CbCard>` with scale icon + "Scale" label + −/+ buttons + tabular-numeral servings count. Scaling re-renders ingredient quantities.
  - Ingredient rows (from `RecipeDocument.Ingredients`): each row has 64px qty (tabular numeral) + name. Row separator with 1px line-bottom border.
  - Tag chips below ingredients (`<CbChip Variant="Tag">` for each `RecipeDocument.Tags`).
- **Right** (method, RV-03):
  - Eyebrow "Method"
  - Each step from `RecipeDocument.Steps`: grid `40px 1fr` columns. Left = hanging accent numeral (28px tabular, color `var(--accent)`). Right = optional step heading (16px bold from `step.Heading` if set) + 15px body paragraph (from `step.Text` for ContentStep, or just heading for SectionStep). If `step.TimerMinutes` set, render `<CbChip Variant="Timer" Icon="clock"> {step.TimerMinutes} min</CbChip>` below.
  - Section steps (SectionStep): render as a heading-style row, no body, no timer chip.

### Task 3: Last-cook notes callout (RV-04)
Below the method, a `<CbCard>` with `background: var(--cream-2)`. Query latest `RecipeMade.Notes` for this recipe (where Notes is not null/empty). If found, render: eyebrow "Notes from your last cook" + quote text + " — {date}". If not found, hide the callout entirely.

### Task 4: Top-bar actions (RV-05)
Set the TopBar right slot via cascading parameter or layout context (mechanism per Phase 5 SHELL-03 design):
- "Share" `CbButton ghost` with `<Icon Name="share" />` — opens existing share dialog via `IDialogService` (MudBlazor coexistence; Phase 7 migrates dialog content).
- "Cook this" `CbButton accent` with `<Icon Name="flame" />` — `Navigation.NavigateTo($"/cook/{recipeId}")`.

If the TopBar's right-slot mechanism isn't fully wired in Phase 5 (it's a CascadingValue), implement the wiring here as needed: add a `[CascadingParameter] LayoutContext Layout` or similar, with a method to set the right-slot RenderFragment. PRAGMATIC: if the wiring is non-trivial, render the actions inline at the top of the page content above the hero; the visual is what matters for Phase 6 SC#3.
