<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → SignalR | multi-file upload bytes cross the circuit |
| user-pasted URL → host | paste-URL HEAD validation |
| AI output → DOM | model-generated text rendered to the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-11 | Denial of Service | Multi-file selection drops the circuit (P14) | mitigate | Sequential per-file `await` foreach; per-file pre-stream 10MB check; GetMultipleFiles(remaining) caps count; existing 12MB SignalR cap unchanged |
| T-14-12 | Tampering / Spoofing | AI helper emits a clickable/embedded image URL (P12) | mitigate | URL-forbidding prompt; output rendered as plain non-clickable text; Uri.TryCreate strip before display; user must manually paste (HEAD gate is final net) |
| T-14-13 | Tampering | Malicious upload (SVG/HTML-as-image → XSS) | mitigate | Reuses LocalRecipePhotoStorage magic-byte sniff (ImageMagicBytes) verbatim per file |
| T-14-14 | Spoofing | Paste-URL SSRF / non-image content | mitigate | RecipePhotoUrlValidator scheme allowlist (step 1) + PhotoUrlHeadValidator 2xx+image/* gate (step 2, AllowAutoRedirect=false) before persist |
| T-14-15 | Information Disclosure | Hot-linked image leaks referrer | mitigate | referrerpolicy="no-referrer" on every gallery img (hero + thumbnails) |
| T-14-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs this plan — zero new NuGet packages (hard invariant). N/A. |
</threat_model>
