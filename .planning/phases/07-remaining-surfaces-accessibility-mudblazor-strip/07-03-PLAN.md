# Plan 07-03: Grocery + grocery dialogs migration

## Goal
Rewrite `GroceryListView.razor` (and any list-detail page if separate) against Phase 5 atoms per `screens/grocery-phone.jsx`. Mobile-first layout that scales sensibly to desktop.
