# Plan 07-06: Accessibility audit + small fixes

## Goal
Run the cross-cutting accessibility audit across all 9 v1.2 surfaces (Home, Cooking Mode, Recipe View, Recipe Editor, Cookbooks list/detail, Pantry, Grocery, AI Chat, Prompt Builder, Profile). Apply minor fixes for any gaps found. Verify visible focus rings, keyboard-only navigation, ARIA roles, and WCAG AA contrast on warm-cream + cocoa-dark themes.

## Tasks

### Task 1: Audit
- Walk through every surface in light mode + dark mode (mental walkthrough — describe what you'd verify in browser, note any issues)
- For each interactive element, verify:
  - Visible focus ring on Tab focus (2px accent-color outline)
  - Reachable via keyboard alone (no mouse-only affordances)
  - Correct ARIA role (`role="button"` on actionable divs, `role="dialog"` on CbDialog cards, `role="menu"` on dropdowns, `role="status"` on toasts, `role="progressbar"` on progress bars)
- For each text + bg combination, verify WCAG AA contrast
- Document findings in 07-06-AUDIT.md

### Task 2: Fixes
Apply small fixes for any gaps surfaced. Common likely fixes:
- Add `:focus-visible` outline to `.cb-btn`, `.cb-row`, `.cb-input`, `.cb-select`, `.cb-toggle`, `.cb-checkbox`, `.cb-radio`, `.cb-chip` (when actionable). Single CSS rule:
  ```css
  .cb-btn:focus-visible,
  .cb-input:focus-visible,
  .cb-select:focus-visible,
  .cb-textarea:focus-visible,
  .cb-row:focus-visible {
    outline: 2px solid var(--accent);
    outline-offset: 2px;
  }
  ```
- Add `role="dialog"` and `aria-modal="true"` to `<CbDialog>` card; `aria-labelledby` pointing at the header
- Add `role="status"` `aria-live="polite"` to toast container
- Add `role="progressbar"` + `aria-valuenow/valuemin/valuemax` to grocery progress bar + cooking step rail
- Verify form atoms have proper `aria-label` or associated `<label>` element
- Verify icon-only buttons have `aria-label`

### Task 3: Build verify + commit
- `dotnet build` clean
- `dotnet test` baseline
- Atomic commit

## Acceptance criteria
- A11Y-01..04 satisfied per ROADMAP.md SC#4
- 07-06-AUDIT.md documents the audit walkthrough + any findings
- All actionable elements have visible focus rings
- WCAG AA contrast verified on key text/bg combinations
- `dotnet build` clean; `dotnet test` baseline
