# Plan 06-01: Home dashboard rewrite

## Goal
Rewrite `Components/Pages/Home.razor` from MudBlazor to the Phase 5 atom system per design handoff `screens/home.jsx`. Lead with the pantry-aware hero, demote stat counters to a glance strip, add Recently cooked + Up next cards.

## Tasks

### Task 1: Pantry-match stub
Add a code-behind file `Components/Pages/Home.razor.cs` (or partial class within `.razor`) with `BuildPantryMatchesAsync()`:
- Inject `CurrentUserService`, `RecipeService`, `PantryService` (or whatever the existing service for pantry items is — check `src/CookBot.Application/Services/` for `IPantryService` or similar).
- For current user: enumerate accessible recipes, get pantry items, compute per-recipe match `% = pantryHasIngredients / recipeIngredients`, sort desc, take top 3 with `match >= 0.6`.
- Returns `List<HomePantryMatch>` records with `Recipe`, `MatchedCount`, `TotalCount`, `MissingIngredientName?` (for "missing parsley"-style chip).
- Add `// TODO: smart matching — FUTURE-13` comment at the threshold check.
- Empty-state: returns empty list when pantry empty or no matches; UI shows CTA.

### Task 2: HOME-01..04 markup rewrite
Rewrite `Home.razor` markup to match `.planning/design-handoff/project/screens/home.jsx` structure. Use the new shell (don't render Sidebar/TopBar — MainLayout handles those). Use atoms: `<CbButton>`, `<CbCard>`, `<CbStat>`, `<CbEyebrow>`, `<StripedPlaceholder>`, `<CbBadge>`, `<Icon>`. Sections:

1. **Greeting** (HOME-01) — eyebrow ("Welcome back, {DisplayName}") + 40px display headline ("What's the kitchen up to tonight?") + quick-actions row:
   - "Generate a recipe" `CbButton accent` with `<Icon Name="spark"/>` — hidden when `_aiOff`
   - "New recipe" `CbButton ghost` with `<Icon Name="plus"/>`
   - "New list" `CbButton ghost` with `<Icon Name="cart"/>`

2. **Pantry-match hero** (HOME-02) — single `<CbCard Padding="28">`. 2-column grid:
   - Left: accent eyebrow ("Tonight from your pantry"), 30px h2 ("Three recipes match what's in stock." OR empty-state heading), 14.5px description, then a list of 3 match rows (each row: tabular-numeral 0X + recipe name + meta + status `<CbBadge>` + arrow icon).
   - Right: `<StripedPlaceholder Height="300" Label="dish photo · primary" />` with overlay chip showing first match's name + duration.
   - When `_pantryMatches.Count == 0`: replace the list with empty-state CTA "Add to your pantry to see what you can cook tonight" + "Manage Pantry" button.

3. **Glance strip** (HOME-03) — 4-col grid of `<CbStat>` tiles: Recipes / Cookbooks / Pantry items / Grocery. Pull counts from existing services. Sub-text per CONTEXT D-04 (PRAGMATIC: simple labels like "in your collection", "shared/private", "{N} low · {N} expiring", "list updated {ago}").

4. **Two-up: Recently cooked + Up next** (HOME-04):
   - Left `<CbCard>` titled "Recently cooked" — 4-col grid of thumbnails (StripedPlaceholder 100% × 92) + recipe name + meta line. Pull from `RecipeMade` ordered by `MadeAt DESC`, take 4. If empty, show empty-state.
   - Right `<CbCard>` titled "Up next" — 3 rows of (clock icon + recipe name + sub-text + more icon). Per CONTEXT D-06: show top 3 starred OR placeholder rows with TODO comment. PRAGMATIC: show 3 placeholder rows for now ("Tartine country loaf — starts 9 PM · autolyse" etc.) with a `// TODO: starred queue` comment.
