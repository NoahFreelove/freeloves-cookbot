# Plan 07-01: Cookbooks (list + detail) + cookbook/recipe dialogs migration

## Goal
Rewrite `CookbookList.razor` and `CookbookDetail.razor` against Phase 5 atoms per `screens/cookbook-list.jsx`. Migrate cookbook-related dialogs from `MudDialog` to `<CbDialog>` + `CbDialogService`: `CookbookFormDialog`, `ShareCookbookDialog`, `ImportCookbookDialog`, `CookbookReferenceDialog`, `SaveRecipeDialog`, `PasteRawTextDialog`, `SectionDropConfirmationDialog`.

## Tasks

### Task 1: CookbookList.razor (CB-01)
- Top action bar: rounded `<CbInput>` search ("Search 128 recipes across 7 cookbooks…") + Filters `CbButton ghost` + grid/list view toggle (two icon buttons in a small toggle group)
- 3-col grid of cookbook cards. Each `<CbCard>` (no padding) contains:
  - 180px header div with cookbook accent tinted background + 3×2 absolute-positioned grid of small striped tiles (using inline `repeating-linear-gradient` per `cookbook-list.jsx`)
  - 18px padding body with: title (17px) + recipe count (right-aligned, tabular numeral) + author meta line (12px ink-3, "Maya · shared with house" or similar)
- Click navigates to `/cookbooks/{id}`
- Buttons in TopBar right-slot: "Import" `CbButton ghost` + "New cookbook" `CbButton accent`

### Task 2: CookbookDetail.razor (CB-02)
- Hero: cookbook title (large, cb-recipe-cap-style or smaller display) + member chips for shared cookbooks + share/PDF/export action row
- Recipe list: each row a CbCard with thumbnail (StripedPlaceholder 80×80) + recipe name + tags + meta (date added, made-count if available)
- Click row navigates to `/recipes/{id}`

### Task 3: Migrate cookbook dialogs (each file in `Components/Pages/`)
For each of `CookbookFormDialog.razor`, `ShareCookbookDialog.razor`, `ImportCookbookDialog.razor`, `CookbookReferenceDialog.razor`, `SaveRecipeDialog.razor`, `PasteRawTextDialog.razor`:
- Replace `<MudDialog>` outer with `<CbDialog @bind-IsOpen="..." MaxWidth="..." OnClose="...">` slots
- Replace `<MudDialogTitle>` content with `<Header>` slot
- Replace `<MudDialogContent>` content with `<Body>` slot
- Replace `<MudDialogActions>` content with `<Footer>` slot
- Replace `MudButton` → `<CbButton>`, `MudTextField` → `<CbInput>`/`<CbTextarea>`, `MudSelect` → `<CbSelect>` + `<CbOption>`, `MudCheckBox` → `<CbCheckbox>`, `MudIcon` → `<Icon Name="...">`
- Update call sites to use `CbDialogService.ShowAsync<...>(...)` instead of `IDialogService.ShowAsync<...>(...)`

`SectionDropConfirmationDialog.razor` (in `RecipeEditorParts/`) gets the same treatment.

### Task 4: Build verify + commit
- `dotnet build` clean
- `dotnet test` baseline
- Atomic commit (or 2 commits if split helps clarity)

## Files affected
- MODIFIED: `Components/Pages/CookbookList.razor`, `CookbookDetail.razor`, `CookbookFormDialog.razor`, `ShareCookbookDialog.razor`, `ImportCookbookDialog.razor`, `CookbookReferenceDialog.razor`, `SaveRecipeDialog.razor`, `PasteRawTextDialog.razor`
- MODIFIED: `Components/Pages/RecipeEditorParts/SectionDropConfirmationDialog.razor`
- MODIFIED: any call site that calls `IDialogService.ShowAsync` for these dialogs
