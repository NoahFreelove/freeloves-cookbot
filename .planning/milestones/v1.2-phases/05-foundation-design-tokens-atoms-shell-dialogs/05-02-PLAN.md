**CbButton.razor** (D-10, ATOM-01):
```razor
@namespace CookBot.Web.Components.Atoms

<button type="@TypeAttr" class="@ClassAttr" style="@StyleAttr" disabled="@Disabled" @onclick="OnClick">
  @if (!string.IsNullOrEmpty(StartIcon))
  {
    <Icon Name="@StartIcon" Size="14" />
  }
  @ChildContent
  @if (!string.IsNullOrEmpty(EndIcon))
  {
    <Icon Name="@EndIcon" Size="14" />
  }
</button>

@code {
    public enum CbButtonVariant { Primary, Accent, Ghost, Subtle }

    [Parameter] public CbButtonVariant Variant { get; set; } = CbButtonVariant.Primary;
    [Parameter] public string? StartIcon { get; set; }
    [Parameter] public string? EndIcon { get; set; }
    [Parameter] public bool FullWidth { get; set; }
    [Parameter] public bool Disabled { get; set; }
    [Parameter] public string Type { get; set; } = "button";
    [Parameter] public EventCallback OnClick { get; set; }
    [Parameter] public RenderFragment? ChildContent { get; set; }

    private string TypeAttr => Type;

    private string ClassAttr => Variant switch
    {
        CbButtonVariant.Primary => "cb-btn",
        CbButtonVariant.Accent  => "cb-btn accent",
        CbButtonVariant.Ghost   => "cb-btn ghost",
        CbButtonVariant.Subtle  => "cb-btn subtle",
        _                        => "cb-btn"
    };

    private string StyleAttr => FullWidth ? "width:100%;justify-content:center" : string.Empty;
}
```
Variant `Primary` is the default (cocoa fill). `Accent` is orange. `Ghost` is transparent + border. `Subtle` is light-gray fill. `StartIcon`/`EndIcon` accept icon-name strings (looked up via `<Icon>`). NEVER imports `MudBlazor`.

**StripedPlaceholder.razor** (D-15, ATOM-06, DS-06):
```razor
@namespace CookBot.Web.Components.Atoms

<div class="cb-ph" style="width:@WidthAttr;height:@HeightAttr;border-radius:@(BorderRadius)px;@Style">
  @Label
</div>

@code {
    [Parameter] public string Width { get; set; } = "100%";
    [Parameter] public string Height { get; set; } = "200px";
    [Parameter] public int BorderRadius { get; set; } = 10;
    [Parameter] public string Label { get; set; } = "photo";
    [Parameter] public string? Style { get; set; }

    private string WidthAttr => Width.EndsWith('%') || Width.EndsWith("px") ? Width : $"{Width}px";
    private string HeightAttr => Height.EndsWith('%') || Height.EndsWith("px") ? Height : $"{Height}px";
}
```
Allows callers to pass either `"100%"` or `"180"` (numeric → treated as px). Default border radius 10px matches the handoff `Stripe` helper in `shell.jsx`.
