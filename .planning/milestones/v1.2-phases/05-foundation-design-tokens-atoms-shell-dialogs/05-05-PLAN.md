<objective>
Replace the MudBlazor-based shell with the custom shell from the design handoff. Rewrite `MainLayout.razor` to use the `cb-shell` CSS grid; create `<Sidebar>`, `<TopBar>`, and `<NavRow>` Razor components; mount `<CbDialogHost>` and `<CbToastHost>` once globally; preserve every behavior the existing layout provides (dark-mode toggle, user-switcher with password prompt, admin Manage-users dialog, AI-off contract).

Purpose: This is the visible Phase 5 outcome. Per D-19/20/21/22, MainLayout is rewritten end-to-end while keeping the application's existing surfaces functional — every page (Home, Cookbooks, Pantry, RecipeEditor, etc.) continues to render *inside* the new shell, even though those pages still use MudBlazor internally (Phase 6/7 migrates their internals). The MudBlazor package remains loaded (D-30) so that internal `Mud*` usage on existing pages keeps working until Phase 7's terminal slice deletes the package.

Key invariants to preserve **exactly** from the existing `MainLayout.razor`:
1. Dark-mode toggle: `cookbot_dark_mode` localStorage key, `body.dark-mode` class via JS interop, restore-on-load in `OnAfterRenderAsync(firstRender)`.
2. User-switcher: load all users in `OnInitializedAsync`; default to "Home Chef" or first user; restore session from `sessionStorage["cookbot_current_user"]` in `OnAfterRenderAsync`.
3. Password-protected user switching: `await UserService.UserHasPasswordAsync(userId)` → if true, launch `PasswordPromptDialog`; on cancel, revert selection.
4. Admin "Manage users" button visible only when `_isAdmin` → launches `AdminManageUsersDialog`.
5. After successful user switch, persist to sessionStorage and `Navigation.NavigateTo(Navigation.Uri, forceLoad: true)`.
6. Auto-create "Home Chef" admin user when no users exist.
7. Cascading `CurrentUserId` value with name `"CurrentUserId"` so existing pages reading this cascading parameter continue to work.

Output:
  - Rewritten `MainLayout.razor` (no Mud*) with cb-shell grid + global hosts + cascading CurrentUserId
  - New `Sidebar.razor` replicating `NavMenu.razor` behavior + adding the design's 6 rows + divider + Profile-bottom layout (SHELL-02)
  - New `TopBar.razor` with menu icon + title/sub/breadcrumb + user-switcher (CbDropdown) + admin button + dark-mode toggle (SHELL-03)
  - New `NavRow.razor` (SHELL-04)
  - `<CbDialogHost />` and `<CbToastHost />` move from `DesignSandbox.razor` to `MainLayout.razor`
  - `NavMenu.razor` is left in place but UNREFERENCED — Phase 7 deletes it as part of MudBlazor strip. (Could delete now; safer to keep as a fallback through Phase 6 in case any rogue reference exists.)

Migration is internal-only. No requirements / DTOs / database / API contracts change.
</objective>

**Create `src/CookBot.Web/Components/Layout/TopBar.razor`** (SHELL-03, D-21):

```razor
@namespace CookBot.Web.Components.Layout
@using CookBot.Web.Services
@using CookBot.Domain.Entities
@inject CurrentUserService UserService
@inject ICbDialogService CbDialog
@inject NavigationManager Navigation
@inject IJSRuntime JS

<header class="topbar">
  <Icon Name="@Icon.Names.Menu" Size="18" />

  <div style="display:flex;align-items:baseline;gap:10px;flex:1;min-width:0;">
    @if (!string.IsNullOrEmpty(Breadcrumb))
    {
      <span style="color:var(--ink-3);font-size:14px;">
        @Breadcrumb <span style="margin:0 6px;color:var(--ink-4);">/</span>
      </span>
    }
    @if (!string.IsNullOrEmpty(Title))
    {
      <span style="font-weight:600;font-size:15px;letter-spacing:-0.01em;">@Title</span>
    }
    @if (!string.IsNullOrEmpty(Sub))
    {
      <span style="color:var(--ink-3);font-size:13px;">@Sub</span>
    }
  </div>

  <div style="display:flex;align-items:center;gap:10px;">
    @RightSlot

    @if (_users.Any())
    {
      <CbDropdown TValue="int" Value="_selectedUserId" ValueChanged="OnUserChanged"
                  Label="@_currentUserName" StartIcon="@Icon.Names.User">
        @foreach (var u in _users)
        {
          <CbDropdownItem TValue="int" Value="@u.Id" Label="@u.DisplayName" />
        }
      </CbDropdown>
    }

    @if (_isAdmin)
    {
      <CbButton Variant="CbButton.CbButtonVariant.Ghost" StartIcon="@Icon.Names.User" OnClick="ShowAdminManageUsersDialog">
        Manage users
      </CbButton>
    }

    <button type="button" class="cb-btn ghost" style="padding:6px;" title="@(_isDarkMode ? "Switch to light mode" : "Switch to dark mode")"
            @onclick="ToggleDarkMode">
      <Icon Name="@(_isDarkMode ? Icon.Names.Sun : Icon.Names.Sun)" Size="16" />
    </button>
  </div>
</header>

@code {
    [Parameter] public string? Title { get; set; }
    [Parameter] public string? Sub { get; set; }
    [Parameter] public string? Breadcrumb { get; set; }
    [Parameter] public RenderFragment? RightSlot { get; set; }

    [Parameter] public bool IsDarkMode { get; set; }
    [Parameter] public EventCallback<bool> IsDarkModeChanged { get; set; }
    [Parameter] public EventCallback OnUserSwitched { get; set; }

    private List<User> _users = new();
    private int _selectedUserId;
    private string _currentUserName = "";
    private bool _isAdmin;
    private bool _isDarkMode;

    protected override async Task OnInitializedAsync()
    {
        _users = await UserService.GetAllUsersAsync();
        if (UserService.CurrentUserId is int uid)
        {
            _selectedUserId = uid;
            _currentUserName = _users.FirstOrDefault(u => u.Id == uid)?.DisplayName ?? "";
        }
        _isAdmin = await UserService.IsCookBotAdminAsync();
    }

    protected override void OnParametersSet()
    {
        _isDarkMode = IsDarkMode;
    }

    private async Task ToggleDarkMode()
    {
        _isDarkMode = !_isDarkMode;
        await IsDarkModeChanged.InvokeAsync(_isDarkMode);
        // The actual JS interop (localStorage write + body class toggle) is owned by MainLayout
        // — TopBar just reports the new value via the bound parameter.
    }

    private async Task OnUserChanged(int userId)
    {
        if (await UserService.UserHasPasswordAsync(userId))
        {
            var parameters = new CbDialogParameters()
                .Add("UserId", userId)
                .Add("UserName", _users.First(u => u.Id == userId).DisplayName);
            var options = new CbDialogOptions(MaxWidth: CbDialogMaxWidth.ExtraSmall, FullWidth: true, CloseOnEscape: true, CloseOnScrim: false);

            // PasswordPromptDialog is the EXISTING MudBlazor-based dialog component.
            // Phase 7 will migrate its internals; for now, CbDialogHost renders it via
            // DynamicComponent and the MudDialogProvider inside MainLayout supplies its host.
            // This works because MudDialogProvider is still mounted alongside CbDialogHost
            // (D-30 coexistence).
            var result = await CbDialog.ShowAsync<PasswordPromptDialog>("Password Required", parameters, options);
            if (result.Canceled)
            {
                _selectedUserId = UserService.CurrentUserId ?? _selectedUserId;
                StateHasChanged();
                return;
            }
        }

        _selectedUserId = userId;
        UserService.CurrentUserId = userId;
        _currentUserName = _users.First(u => u.Id == userId).DisplayName;
        try { await JS.InvokeVoidAsync("sessionStorage.setItem", "cookbot_current_user", userId.ToString()); }
        catch { /* prerender — ignore */ }
        await OnUserSwitched.InvokeAsync();
        Navigation.NavigateTo(Navigation.Uri, forceLoad: true);
    }

    private async Task ShowAdminManageUsersDialog()
    {
        var parameters = new CbDialogParameters()
```
